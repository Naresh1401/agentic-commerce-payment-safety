# AP2-Style Payment Safety Simulation

Standalone repository split from `agentic-commerce-platform`.

## What This Demonstrates

Mock payment mandate, idempotency, duplicate blocking, success, decline, and audit trail simulation.

This is a demo/training project. It uses mock grocery data only. It does not use real Kroger APIs, real payment APIs, real customer data, or secrets.

## Setup

```bash
make setup
```

## Run

```bash
make run
```

## Verify

```bash
make test
```
